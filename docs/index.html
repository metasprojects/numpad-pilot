Reels while you wait.
Gone when you fly.

A small Instagram Reel window that sits over War Thunder in borderless mode. Scroll, pause, and adjust it with the numpad. Press 0 to hide it fast.

View on GitHub ↗

What it does

  • Shows only the Reel video during play, with no sidebar or scroll bars.
  • Lets you control Reel volume in 2% steps and window opacity separately.
  • Moves the cropped Reel with numpad decimal and 8 / 2 / 4 / 6 while the game stays focused.
  • Shows a small confirmation inside the Reel when you like or unlike it.
  • Hides, pauses, and mutes with one key. Showing it restores playback if it was playing.
  • Opens Instagram's comment and Send controls in a larger clickable view, with a small confirmation cue.

Default keys

You can change these in the app settings.

8 / 2Previous / next Reel
5Pause / play
4 / 6Volume down / up by 2%
7 / 9Opacity down / up
+ / -Like / unlike
/Comment
*Save / unsave
1 / 3Send / Share · More
0Hide / show
.Move Reel / save position
EscClose Comment / Send view

All number keys above are on the numpad. Comments are typed and submitted by you.

Set it up

  1. A Windows installer is being tested. Once released, run it and open Numpad Pilot from the desktop or Start menu shortcut.
  2. For now, developers can build the installer from source with npm ci and npm run dist:win.
  3. Sign in through Instagram's page in the app. If the sign-in page is cropped, choose Open Instagram view from the tray menu. Set War Thunder to borderless windowed.

Current status

The source is public as a work in progress. The app works in local Windows tests, but it has not yet been tested in War Thunder with BattlEye enabled. This project is unaffiliated with Gaijin, BattlEye, Meta, and Instagram.
